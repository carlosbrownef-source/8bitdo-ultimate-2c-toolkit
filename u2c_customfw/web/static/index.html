How this app works

  
Out of the box, macOS and most Mac games don't recognise the 8BitDo Ultimate 2C Wireless as a standard controller. This app changes the controller's firmware (the software inside it) so that they do. It only works with firmware 1.09.

  
1. Back up

  
Saves a full copy of the controller's memory on this Mac. It changes nothing on the controller. It is required before the first change, so you can always restore the controller exactly as it was.

  
2. Tweaks

  
    
    
  • Xbox Series X|S controller over Bluetooth. macOS recognises only a few controllers, such as Xbox and PlayStation ones. Over Bluetooth the 2C normally isn't one of them, so games don't see it. With this tweak it introduces itself as an Xbox Series X|S controller, which macOS and its games support.
    • 
    
  • Rumble over Bluetooth. The original firmware doesn't vibrate over Bluetooth. This tweak makes the controller respond to the rumble commands games send. It needs the Xbox tweak, because it uses the Xbox rumble commands.
    • 
    
  • Xbox 360 controller over cable. Connected by cable, the controller introduces itself as a wired Xbox 360 controller, a type macOS recognises.
    • 
    
  • Dimmer LEDs. Slightly lowers the brightness of the controller's three lights. It is subtle: to really change the ring around the Home button, use Home ring brightness.
    • 
    
  • Home ring brightness. Sets how bright the ring around the Home button is while the controller is connected: Normal keeps its usual brightness, and the percentages are how much of the time the light is on, not how bright it looks. It still blinks while searching or pairing, at its usual brightness, and settles at your level once connected. Off keeps it dark while connected. You can change it at any time with L4 + R4 on the controller, or in the Settings tab, and the controller keeps the level you saved until you install a different one here. Choosing the level already installed changes nothing, so to go back to it, use the Settings tab.
    • 
    
  • Controller settings. Adds what the Settings tab changes: sticks, triggers, L4 and R4, vibration, power and button remapping. With everything at its default, the controller runs its original code for these.
    • 
    
  • Fixes. Moving a stick counts as using the controller, so playing only with sticks no longer turns it off after 15 minutes. A dropped connection gets its full search time. Unplugging the cable with the switch in the Bluetooth position restarts the controller, so it finds the Mac at once. It also closes the firmware update over Bluetooth, which needs no encryption.
    • 
    
  • Finer stick movement. The firmware ignores small stick changes, which makes slow movement advance in small jumps. This lowers that limit to just above the noise measured on one controller. A stick held still away from the centre may still move by one step now and then.
    • 
    
  • Battery alerts. The ring blinks slowly while charging and quickly when the battery is at 15 % or less, even if you turned it off. The motors give one short pulse when charging starts, one long pulse when it completes, and two short pulses at 5 % or less, again every 5 minutes. These only work with a Home ring level, so with this on and the brightness on Normal, the ring's code is installed at full brightness.
    • 
  

  
The tweaks are always added to 8BitDo's original firmware 1.09, taken from your backup or downloaded from 8BitDo, so the result is always a known, checked firmware.

  
Update mode

  
The controller can only receive new firmware in update mode. Turn it fully off, then hold L1 + R1 while plugging in the cable. The light will blink white.

  
Check first

  
Runs every check without changing anything: that this is the same controller as in your backup, that its firmware is one the app knows, and that the new firmware is complete.

  
3. Restore

  
Restores your backup, or 8BitDo's original firmware 1.09. Use it if something doesn't work, or to use 8BitDo's own apps and updates again.

  
After installing

  
Unplug the controller. If you changed a Bluetooth tweak, remove the controller from Bluetooth settings and pair it again, because macOS remembers how a device introduced itself the first time.

  
Settings

  
This tab changes the controller while it's connected by cable, once the Controller settings tweak is installed. A change applies at once and is lost when the controller turns off or restarts, unless you press Save to controller. Opening this tab again also goes back to what's saved. Reset to defaults puts these settings back, apart from the Home ring and the calibration, and works without pressing any buttons on the controller.

  
Restoring the firmware doesn't erase them. The original firmware ignores most of them, and they apply again if you install the tweak again, but it does keep using the L4 and R4 mappings and the dead zone switch, because those are its own. Use Reset to defaults first if you want those gone. While this tab is open, as with the controller test, Home doesn't open Apple Games.

  
Home ring changes the ring at once, over Bluetooth or by cable, without installing anything. Save keeps it.

  
Diagnostics

  
This tab helps you check how macOS sees the controller, and gather information if something goes wrong.

  
Controller test shows what macOS's GameController reports, which is what a game gets, including the battery when macOS provides it. Press each control to see it light up, and use the buttons to make the controller vibrate. "Vibrate like a game" uses the same path as native games, and "Direct report" goes straight to the controller, so if only the direct report vibrates, the firmware isn't the problem. The first time you press the Home button in this test, macOS may ask for your permission to let the app receive it. If you allow it, Home won't open Apple Games while this tab is open. This test is only available in the Mac app.

  
The controller also has its own option for the sticks: holding Start + Select for about 4 seconds switches a 14 % dead zone on the sticks on and off. The controller buzzes once when it turns on and twice when it turns off, and it remembers the setting. It's part of 8BitDo's firmware.

  
Firmware details shows what the app read from the controller, including where the version came from and whether a firmware update is pending.

  
Create a problem report collects the controller's state and the last task's log for a bug report. It never includes the controller's address, its Bluetooth pairings or your backup.

  
Install firmware 1.09 anyway is only for a controller whose firmware can't be identified. It erases the firmware and installs 8BitDo's original 1.09 without being able to check beforehand that it's right for the controller, so use it only if Restore doesn't work.
