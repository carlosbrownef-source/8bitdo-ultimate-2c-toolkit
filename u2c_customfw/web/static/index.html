    WARNING — force install without knowing the version
    
  
      
    
    • This app cannot tell which firmware this controller runs, and cannot check that v1.09 is right for it.
      • 
    
    • It will erase and rewrite the controller's main firmware with 8BitDo's v1.09. If the controller really runs another firmware generation, it may not start afterwards, or buttons, Bluetooth, battery or rumble may misbehave.
      • 
    
    • The bootloader is never touched, so boot mode keeps working. A backup of this unit is required first, and Diagnose and restore can put that backup back.
      • 
    
    • Pairings and the controller's identity (MAC, calibration) are not changed.
      • 
    
    • It voids the warranty, and no warranty of any kind applies.
