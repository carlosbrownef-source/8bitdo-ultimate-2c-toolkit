Before you start

Controller

    1. Back up

    Plug the controller in by cable. This reads its whole flash twice and saves it; needed before the first write.

    2. Patch

    Built from stock v1.09:

    Power the controller fully off, then hold L1+R1 while plugging in the cable. The LED blinks white.

    3. Diagnose and restore

    In boot mode (as above). Restoring puts back your backup or 8BitDo's v1.09.
